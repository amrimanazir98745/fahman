Fahman MHD
==========
Open index.html in a browser, or upload this whole folder to any static host
(Netlify, Vercel, GitHub Pages, cPanel). Keep the media/ folder next to index.html.

Edit content in the <script> near the bottom of index.html:
  CATS   - the 6 categories (picture on the arc + "about" text shown in Services)
  WORK   - your work for the carousel. {src:"file.jpg", t:"Title", cat:"design"}
           videos: {video:"name", t:"Title", cat:"drone"} needs media/name.mp4 + media/name.webp (poster)
           cat ids: design, photo, video, thumb, drone, podcast
  SKILLS - software and percentages
Social links: search for "facebook.com", "instagram.com", "tiktok.com" in index.html.
Colours: --bg, --ink, --accent at the top of the <style> block.
Font: Plus Jakarta Sans (Google Fonts).
